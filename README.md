# MLOps Project

MLOps pipeline with data ingestion, cleaning, model training, and drift monitoring using Evidently.

## Features
- 📥 Data ingestion and cleaning
- 🤖 ML model training with MLflow
- 📊 Data drift monitoring with Evidently
- 🐳 Docker support

## Quick Start
```bash
python3 src/ingest.py
python3 src/clean.py
python3 src/train.py
python3 src/monitor.py
```

## Tech Stack
- Python 3.12
- MLflow
- Evidently
- Pandas
- Scikit-learn
